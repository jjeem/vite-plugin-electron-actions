# Security Policy

## Supported Versions

Only the **latest released version** of `vite-plugin-electron-actions` is
supported and receives security updates. Older releases are not supported.

Before reporting an issue, please verify that it affects the latest published
release.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through the repository's
[Security page](https://github.com/jjeem/vite-plugin-electron-actions/security).
Do not disclose the vulnerability in a public GitHub issue or discussion.

Include the following information when possible:

- The affected version
- A description of the vulnerability and its potential impact
- Steps to reproduce the issue or a minimal proof of concept
- Any known mitigations or workarounds

Please allow time for the report to be investigated before publicly disclosing
the vulnerability.
