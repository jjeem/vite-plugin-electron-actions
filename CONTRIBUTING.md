# Contributing

Contributions are welcome. Before making a significant change, please open an
issue to discuss it with the maintainers.

## Development

Install the dependencies:

```bash
pnpm install
```

Before submitting a pull request, run:

```bash
pnpm run typecheck
pnpm run check
pnpm run test
```

Keep changes focused, include tests when behavior changes, and clearly describe
the purpose of the change in the pull request.

For security vulnerabilities, follow the private reporting process in
[SECURITY.md](SECURITY.md) instead of opening a public issue.
